# Bundled Anime4K shaders

These GLSL shaders come from Anime4K v4.0.1:

- Source: https://github.com/bloc97/Anime4K
- Release: https://github.com/bloc97/Anime4K/releases/tag/v4.0.1
- License: MIT, see `LICENSE.txt`

The files are loaded by mpv when enhanced playback is enabled. Custom shader
paths in SakuraFall settings override this bundled set.
