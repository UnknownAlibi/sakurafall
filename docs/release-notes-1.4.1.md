# SakuraFall 1.4.1

1. 更新中心重构：应用更新入口移至标题栏全局更新卡片，检查更新、下载进度、安装重启一站式完成，切换页面不再中断或丢失状态。
2. 更新安装改为两段式：下载完成后停留在待安装状态，由用户确认后再执行静默安装并重启，避免正在看番时被强制打断。
3. 更新链路安全加固：安装包支持 sha256 校验，下载文件名增加路径逃逸防护，安装命令限定只执行更新目录内的文件。
4. 修复启动时弹幕配置同步异常可能导致更新提醒与下载进度长期静默失效的问题。
5. 新增数据库版本防线：本地数据库由更新版本创建时，旧版本应用会明确提示升级而不是带病运行。
6. 修复 BT 边播边下 IPC 注册时序问题，并加固 IPC 来源校验。
