# SakuraFall 1.4.3

1. 主窗口改为无边框界面：去掉实体标题栏，顶部透明拖拽区搭配右上角悬浮窗口控件，内容从窗口顶部满幅铺开，品牌标识保留在左上角。
2. 主窗口与播放页统一视觉语言：页头、筛选器、卡片、详情页、选集侧栏和播放控制条采用同一套圆角与材质层级；除动漫卡片外，顶栏、页头和设置分区融入氛围背景。
3. 播放器控制条改为底部悬浮面板，进度条上移，分集侧栏、一起看、弹幕设置、手帐和投屏浮层同步优化。
4. 修复视频流代理启用后，DLNA 投屏与外部 mpv 增强播放收到内部代理地址而无法打开的问题；投屏同时携带原始请求头。
5. 修复手动切集或切线路时旧自动连播倒计时未取消，可能在 2 秒后覆盖用户刚选集数的问题。
6. 安全加固：一起看房间号强制校验并限制错误尝试频率，共享载荷剥离播放直链和 Token；设置页代理、弹幕 Token、OpenSubtitles API Key 等改用系统安全存储加密；IPC 路径与主窗口权限默认收紧；跨域重定向不再携带认证头。
7. 可靠性改进：SQLite 延迟写入失败后保留队列并重试，数据库关闭可重复调用；下载器统一走应用代理并限制重定向和清单大小；图片缓存增加 30 天过期回收。
8. 修复自动更新安装目录含空格时的 NSIS 参数处理，避免更新安装到错误路径。
