# SakuraFall 特色功能路线

## 目标

SakuraFall 不再只做“能搜索、能选集、能播放”的桌面壳。四条特色主线共享同一套剧集身份、播放路线和时间轴协议，功能之间可以互相增益，同时不把具体视频站点写死在核心代码中。

## 统一底座

### Episode Identity

- 首选 Bangumi subject id 作为作品身份，离线时使用规范化标题兜底。
- 剧集优先使用集数，无法提取时使用规范化集标题或剧集 id。
- 身份示例：`bgm:400602|ep:12`。
- 身份不包含 CMS/XPath 源 id，因此切换源、导入新源包或一起看使用不同线路时仍指向同一集。

### Timeline Anchor

- 同时保存绝对秒数、片源时长和归一化进度。
- 两条片源时长差不超过 4% 时使用绝对秒数；差异更大时按进度比例换算。
- 后续 Episode DNA 可以用片头偏移、关键帧指纹进一步校准，但不会破坏 v1 数据。

### Playback Session

- 统一记录解析、首帧、卡顿、丢帧、失败、候选线路和恢复位置。
- 所有评分只使用本机匿名运行指标，不上传播放记录、笔记或地址。

## 1. SakuraRoute 智能线路

### 已完成 P0

- CMS 候选源在进入播放器前完成清单探测、画质与历史健康度排序。
- 播放器展示 `线路稳定 / 预检中 / 正在无缝换线 / 线路波动` 状态。
- 候选面板标记推荐线路，并展示健康度、首帧、卡顿率和广告反馈。
- 致命网络或解码故障自动尝试其他源，保留当前播放进度。
- 路线会话记录已尝试源，避免同一轮恢复重复撞线。

### P1（已完成）

- 播放前并行预热前两条候选线路，但只读取清单和极小媒体片段。
- 将 DNS、403、空清单、广告反馈、持续卡顿拆成不同惩罚窗口。
- 在设置页提供“稳定优先 / 清晰优先 / 低延迟优先”，默认稳定优先。

### P2

- 为本地源包生成可导出的匿名健康摘要；用户明确同意后才允许共享。
- 允许规则包声明备用解析器，不允许规则包执行任意本地代码。

## 2. Episode DNA 剧集指纹

### 已完成 P0

- 已有跨源 Episode Identity 和 Timeline Anchor。
- 换源续播与一起看同步可以跨不同编码时长对齐。

### P1（已完成）

- 保存用户确认过的片头、片尾、广告和关键剧情时间段。
- 同作品相邻剧集使用音频能量与场景切换寻找候选片头区间，只做建议，不自动跳过。
- 至少三集候选位置稳定且用户确认后，才升级为自动跳过规则。

### P2

- 可选生成低分辨率感知哈希和短音频指纹，用于不同源之间的亚秒级对齐。
- 指纹仅保存不可逆摘要，不保存视频帧或音频内容。

## 3. 樱月手帐

### 已完成 P0

- 播放控制栏提供手帐入口。
- 可在当前时间点创建文字时光签、跳回时间点和删除。
- SQLite 持久化以 Episode Identity 归档，换源后仍可见。
- 数据库 schema v6，旧数据自动迁移并在迁移前备份。

### P1（已完成）

- 将时光签渲染为进度条标记，并提供“台词、伏笔、作画、音乐”轻量分类。
- 详情页增加无剧透的个人回顾，仅显示已看进度之前的记录。
- 支持导出 Markdown；导入时按 Episode Identity 去重。

### P2

- 用户主动选择时截取当前帧作为私有缩略图，失败时仍保留文字记录。
- 樱月基于用户自己的记录生成本季回顾，不读取未观看剧集内容。

## 4. 跨源一起看

### 已完成 P0

- 已有本地 WebSocket 房间、播放/暂停、进度、倍速和聊天同步。
- 房间状态新增 Episode Identity，防止不同集之间错误 seek。
- 同步状态新增 Timeline Anchor，成员可使用自己的片源并按时长差异对齐。

### P1（已完成）

- 成员收到不同集状态时先显示“主机已切到第 N 集”，确认本地候选源后再切换。
- 使用单调时钟估计网络延迟，以软调速代替频繁硬 seek。
- 房间只发送身份和时间轴，不发送主机真实视频 URL。

### P2

- 支持临时端到端加密房间密钥和中继服务器；本地局域网模式继续保持零账号。
- 手帐时光签可选择在房间内临时共享，默认仍为私有。

## 性能约束

- 播放期间禁止为这些功能新增逐帧 Vue 响应式更新。
- 路线状态只在解析、首帧、卡顿、失败和切源节点更新。
- Episode DNA 的分析必须运行在 Worker 或主进程低优先级任务中，并可随时取消。
- 手帐查询按单集索引读取；一起看状态保留现有节流，不因 UI 打开提高广播频率。
- 所有新播放器面板必须按需挂载，关闭后释放监听器与定时器。

## 验收指标

- 自动换源成功后恢复误差小于 2 秒。
- 同集不同时长片源的一起看初始对齐误差小于 3 秒，稳定后小于 1.5 秒。
- 手帐新增、查询和删除在本地数据库 P95 小于 30ms。
- 关闭所有特色功能时，播放 CPU、GPU 和内存占用不高于改造前基线。
