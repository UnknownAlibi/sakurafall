# SakuraFall 1.4.2

1. 修复部分宽银幕片源（如 1920×804 的 2.39:1 视频）全屏播放时视频下方出现空白、进入全屏画面闪烁的问题。
2. 修复全屏模式下移动鼠标无法呼出底部控制栏的问题。
3. 播放器窗口状态修复：全屏尺寸不再被误存为普通窗口尺寸，恢复窗口时按屏幕工作区钳制，避免窗口超出屏幕。
4. 修复播放中偶发"播放/暂停按钮持续闪烁"的问题：异常暂停自动恢复不再无限重试，内部缓冲暂停不再误触暂停态 UI。
5. 兼容性说明：Windows 11 24H2 + 部分混合显卡机型存在系统级显示合成缺陷（Chrome/Edge 同受影响），本版本播放器改用兼容的合成路径规避，全屏显示恢复正常；视频硬件解码不受影响，播放时 CPU 占用略有增加。
