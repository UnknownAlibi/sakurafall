# SakuraFall 1.3.2

1. 优化番剧目录同步：大目录改为 Worker 分批解析和写入，降低首次同步期间的内存与界面卡顿。
2. 优化封面加载：可见封面优先，离屏请求可取消；相同图片跨窗口共享下载，减少重复请求。
3. 优化详情加载：关闭详情或切换筛选后及时取消无用请求，避免旧结果覆盖当前页面。
4. 修复目录更新中分页版本变化、服务器异常时本地列表不稳定、断网模式仍旁路请求远端封面，以及详情时间字段迁移不完整和健康检查误报的问题；v10 迁移会自动修复运行过早期开发构建的本地数据库。
5. 修复服务端目录扫描短页漏项、失败时发布不完整目录的问题，并限制快照响应缓存内存。
6. Anime4K 实时增强标记为实验功能；保留 GPU 输出校验、性能降档和回退保护。

已知限制：Anime4K 的实际效果和实时帧率受显卡、驱动、源分辨率及编码格式影响；性能不足时应用会自动降低档位或回退到兼容显示增强。
